# Toaster

Toaster is a mobile application that allows users to compress the size of their uploaded photos and videos, providing them with the ability to download media in their desired size. Developed using the BLoC pattern, Toaster offers a user-friendly interface and fast processing capabilities to help you manage your media files effortlessly.

## Features

- **Media Compression**: Users can upload photo and video files to reduce their sizes.
- **Fast Download**: Allows users to download media files in their desired size after compression.
- **User-Friendly Interface**: Simple and intuitive design makes it easy for users to navigate the app.
- **Multilingual Support**: The application supports both English and Turkish languages.
- **Enhanced Performance**: Fast compression algorithms quickly process users' files.

## Usage

1. Open the application.
2. Click on the "Pick Image" or "Pick Video" button to upload a media file.
3. The application will automatically process the uploaded file and display its size.
4. Click the "Download Media" button to download the compressed file.
5. You can find the downloaded file on your device.
